# Always-On: The Philippine Pop Culture Time Machine

A faithful reproduction of https://rastyfullstaxx.github.io/always-on/, prepared at the repository owner's request. The original site's content, credits, research references, visuals, and JavaScript interactions are preserved.

## Preview locally

Run `python3 -m http.server 8000` in this folder and open http://localhost:8000/.

This is a static HTML/CSS/JavaScript website. No dependencies or build step are required. Assets are included locally; the original website does not need to be available.

## GitHub Pages

In Settings → Pages, choose Deploy from a branch, then `main` and `/ (root)`.
